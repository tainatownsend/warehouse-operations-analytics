# Data

## Planned Source

**Dataset:** Logistics Operations Database  
**Publisher:** Yogape  
**Platform:** Kaggle  
**Source page:** `https://www.kaggle.com/datasets/yogape/logistics-operations-database`

## Important Limitation

The dataset is synthetic. It is suitable for demonstrating data modeling, SQL, analytics, visualization, and operational reasoning, but it must not be presented as evidence about a real organization.

## Directory Rules

### `raw/`

Contains source files exactly as acquired.

Rules:

- Do not edit raw files.
- Do not commit large raw data files.
- Record acquisition details and checksums.
- Preserve original filenames.

### `processed/`

Contains reproducible outputs created from raw data.

Rules:

- Every processed file must be generated by code.
- Do not edit processed files manually.
- Document the transformation that created each output.
